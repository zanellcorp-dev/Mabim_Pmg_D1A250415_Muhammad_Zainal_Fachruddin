### Deskripsi:
Sistem login admin sederhana dengan fitur:
1. Desain Glassmorphism.
2. Validasi input menggunakan JavaScript.
3. Manajemen session menggunakan PHP  dan `session_start()` bwt melindungi halaman Dashboard.
4. Fitur Show/Hide Password.

## 🛠️ Menggunakan
- **PHP 8.x** (Back-end)
- **HTML5 & CSS3** (Front-end)
- **FontAwesome 6.4.0** (Icons)
- **Google Fonts (Poppins)** (Typography)
